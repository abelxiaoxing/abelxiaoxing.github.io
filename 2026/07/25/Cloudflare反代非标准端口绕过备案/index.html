Cloudflare DNS Only：非标准端口直连 HTTPS

发表于 2026-07-25 更新于 2026-08-05

将 Cloudflare 记录切换为 DNS Only 后，请求会直接到达源站，浏览器也会直接校验源站证书。要在 8443 等非标准端口上提供可信 HTTPS，只需通过 DNS-01 签发 Let’s Encrypt 证书，并由 Nginx 加载。

DNS-01 不依赖 80/443 端口，也不需要临时自签名证书。本文按 签发证书 → 配置 Nginx → 验证源站 → 切换 DNS 的顺序操作。

DNS Only 仅使用 Cloudflare 权威 DNS。源站 IP 将公开，CDN、WAF、Cloudflare Access 等代理能力也会失效。备案和网络接入要求请遵守当地法规及云厂商规则。
